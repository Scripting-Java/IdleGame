# TimeForge

TimeForge is an idle game where the main goal is to *\*you guessed it\** make money.

Start small, build your business empire with farms and workshops, and work your way toward industrial domination. Purchase businesses, invest in upgrades, and watch your income grow! 

## How To Play:
- **Earn money:** Generate income by owning businesses.
- **Earn more money:** Purchase new businesses to earn more money faster.
- **Upgrade to earn even more money:** Invest in upgrades to enhance a specific part of a business and make it earn money faster, earn more per cycle, and give you a chance at earning a "jackpot".
- **Warning**: Waiting a long time for a higher tier and paying the unlock cost does not give you the business so make sure you play the "right" way and build your way up instead of saving it all. 

### Business Types

| Type | Description |
|---|---|
| 🌾 Farms | Agriculture and animal products. That's what's on farms |
| 🔨 Workshops | Expand into skilled trades and workshops. |
| ⚙️ Industry | Raw materials that make up the backbone of any economy. |
| 🏭 Factories | Build advanced and modern businesses to maximize your wealth. |

## Running it locally
### Prerequisites

To run the project locally, install:

- [Node.js](https://nodejs.org/) — the latest LTS version is recommended.
- npm — included with Node.js.
- [Git](https://git-scm.com/) — you can git clone, but it would probably be easier to download the file from github.

### 1. Download the project

Choose either method below.

#### Option A: Clone with Git
*Note:* It's probably much easier to just download the file from github instead for most people.
Make sure [Git](https://git-scm.com/) is installed, then open a terminal and run:

bash git clone https://github.com/Scripting-Java/TimeForge.git


#### Option B: Download as a ZIP
1. Download the zip file from the repository on github.
2. Extract the ZIP file to a folder on your computer. 
3. Open a terminal in the extracted project folder. You can use cd for windows terminal, or just type powershell in file explorer path.

### 2. Install dependencies

For either option, make sure [Node.js](https://nodejs.org/) is installed. npm is included with Node.js.

In your terminal(in the game directory) run:

```bash
npm install
```

Installs dependencies 

### 3. Run the game locally

```bash
npm run dev
```
Starts the server.

The terminal will display a local URL, usually:

```text
http://localhost:5173/
```

Open that URL in your browser to run TimeForge. Keep the terminal open while playing.


## 🛠️ Development Commands

| Command | Purpose |
|---|---|
| `npm install` | Install project dependencies |
| `npm run dev` | Start the development server |
| `npm run build` | Check TypeScript and find any errors. There shouldn't be any, but if there are it might be a node version difference. The device this was tested on has node version v24.19.0 and node package manager version 12.0.2|
| `npm run lint` | Typescript checker|
| `npm test` | Tests when I was initally making the production and mechanics.|
